# Exploring-Hate-Speech-in-Online-Space
Research artifacts, code, experimental results, datasets, and supporting materials for a thesis on topic modeling and hate-speech/sexism-related social media text analysis.

# Thesis Research Artifacts

This repository contains the research artifacts associated with the thesis on
topic modeling and the analysis of hate speech and sexism in social media
datasets.

The repository includes source code, preprocessing procedures, experimental
configurations, model outputs, evaluation results, visualizations, and
supporting materials used throughout the study.

## Repository Contents

### 1. Data Preprocessing
- Data cleaning and preprocessing scripts
- Duplicate removal procedures
- Preprocessed dataset information
- Deduplication results

### 2. Exploratory Data Analysis
- Dataset statistics
- Class distributions
- Exploratory visualizations
- Analysis outputs

### 3. Sentiment Analysis
- Sentiment analysis code
- Experimental configurations
- Sentiment analysis results
- Generated visualizations

### 4. Topic Modeling
Experiments with different topic modeling approaches:

- Standard LDA
- Ensemble LDA
- Twitter-LDA

This section includes:
- Parameter selection experiments
- Model configurations
- Evaluation metrics
- Topic-word distributions
- Topic visualizations
- Stability analysis
- Selected model configurations

### 5. Dataset-Specific Experiments

Experiments are organized according to the datasets used in the thesis,
including:

- HASOC 2019
- HASOC 2020
- HASOC 2021
- EXIST 2021
- GESIS

Where applicable, experiments are further divided into:
- Whole dataset
- HOF classification
- NOT-HOF classification

### 6. Model Evaluation
Evaluation artifacts include:

- Topic diversity
- Topic stability

- Document assignment overlap

### 7. Experimental Logs
Training and evaluation logs generated during model execution.

### 8. Model Outputs
Saved models, dictionaries, topic-word distributions, metrics, and other

### 9. Visualizations
Plots and figures generated for:

### 10. Thesis Supporting Materials
Additional tables, experimental records, and supplementary materials

## Experimental Reproducibility

The repository is intended to provide a record of the experimental process
and supporting artifacts used in the thesis. Experimental configurations,
random seeds, model parameters, evaluation metrics, and generated outputs
are retained where applicable.

## Datasets

The experiments use publicly available or previously obtained datasets.
Dataset files are not necessarily redistributed in this repository where
their licenses or usage conditions do not permit redistribution.

Where datasets cannot be included directly, instructions or references for
obtaining the corresponding datasets are provided where appropriate.

## Thesis

This repository serves as a supplementary resource for the thesis and
contains the artifacts supporting the experiments, results, and analyses
reported in the thesis.
